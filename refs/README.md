# Fotos de referencia

Añade imágenes propias o que puedas usar a `refs/<perfil>/<parte>/`. Por ejemplo,
`refs/stone-island/badge/parche.jpg` y `refs/stone-island/neck_label/etiqueta.jpg`.
Usa una parte por carpeta y fotos nítidas de distintas prendas y ángulos. El perfil
puede señalar otra carpeta con `refs_dir`. Las coincidencias ORB solo indican que
aparece una parte con rasgos similares.

Guarda las fotos de catálogo que quieras detectar en `refs/stock/`. El sistema
compara su huella perceptual con la de cada foto descargada. Las dos funciones
admiten carpetas vacías.
